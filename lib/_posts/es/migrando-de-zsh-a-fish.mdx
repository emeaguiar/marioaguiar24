Hace un par de meses por diversas cuestiones tuve que reformatear mi computadora personal, lo que me ha llevado a tener que re-configurar casi todo mi ambiente local y mis herramientas, durante este proceso, he estado tratando de aprovechar la situación y tratar de actualizar mis herramientas, con las que he estado trabajando por la mayor parte de los últimos diez años.

Entre ellas se encuentra **Z Shell** (zsh) y [Oh My Zsh](https://ohmyz.sh/), la cual me agrada mucho, pero recientemente he estado escuchando muy buenas cosas acerca de **Fish[^fish]** , he decidido darle una oportunidad e intentaré mover mis configuraciones desde zsh hacia fish, aquí está el resultado de este experimento:

> [!CAUTION] Advertencia
> En este artículo he colocado varios _prompts_ para ser utilizados en la terminal, todos son seguros, pero no está de más darles una leida y asegurarse de que no haya nada raro en ellos

## PREPARATIVOS

### Fish (duh)

Antes que nada tuve que instalar fish, esto resultó muy sencillo porque ya tengo [homebrew](https://brew.sh/) instalado en mi sistema, simplemente se ejecuta el comando:

```bash
> brew install fish
# confirmamos
> fish --version
fish, version 4.9.0 
```

### Fisher (_plugin manager_)

Investigando un poco me doy cuenta de que hay más de un tipo de _plugin manager_ para fish, he leido que existe Oh My Fish el cual se supone que funciona muy bien si ya estás utilizando OMZ, pero como estamos experimentando esta vez me iré por [Fisher](https://github.com/jorgebucaran/fisher), el cual parece ser el más popular.

```bash
> curl -sL https://raw.githubusercontent.com/jorgebucaran/fisher/main/functions/fisher.fish | source && fisher install jorgebucaran/fisher
```

## CONFIGURANDO **FISH**

Ahora que tenemos lo que necesitamos instalado, vamos a configurar el prompt, yo acababa de comenzar a utilizar Starship y me gustó mucho como quedó de simple, así que trataré de emularlo.

### El archivo de configuración

Como era de esperarse, primero necesitamos crear el archivo de configuración, para fish este se encuentra en el directorio `$HOME/.config/fish` así que lo creamos:

```bash
> mkdir -p $HOME/.config/fish
> echo "starship init fish | source" >> $HOME/.config/fish/config.fish
```

> [!IMPORTANT]
> Como mencioné anteriormente, yo ya tenía Starship instalado, pero si no lo tienes se puede instalar fácilmente usando homebrew:
> 
> ```bash
> > brew install starship
> ```
> 
> Y este es mi archivo de configuración:
> 
> ```toml
> "$schema" = 'https://starship.rs/config-schema.json'
>

$git_state\
$git_status\
$cmd_duration\

>
[directory]

>
[character]

error_symbol = "[❯](red)"
vimcmd_symbol = "[❮](green)"
>
[git_branch]

>
[git_status]

>

>
